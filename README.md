## What it does

`main.py` writes one satirical sentence to `/output/entry.txt`:

> The senator who spent six hours grilling the AI CEO about alignment just sent his own bill to the clerk as a photograph of his laptop screen.

The joke sets up the lawmaker's authority — six hours interrogating an AI
CEO about alignment — and undercuts it with the file he cannot convert:
his own bill only reaches the clerk as a photograph of his laptop screen.

## How to run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # writes to a path of your choice
```

Python 3 only, standard library only, no network, no input. The output is
a fixed string, so repeated runs are byte-identical.
